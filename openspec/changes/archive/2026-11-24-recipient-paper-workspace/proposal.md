# Proposal

## Why

The static sender proves secure raster delivery. It needs a workspace for choosing people, preparing a print, and sending it without exposing bench controls in the main flow.

## What Changes

- Put People beside Paper on desktop. On narrow screens, use separate People and Paper views with single-tap and long-press selection.
- Send a text note or one full-width image using the exact monochrome raster shown on Paper. Replace mixed composition for this version.
- Send directly to the selected people and report broker acknowledgment per recipient. Put manual sender setup on a separate Settings page.

### New Capabilities

### Modified Capabilities

- `browser-sender`: Adds responsive recipient selection, exclusive content modes, and per-recipient send results.

## Impact

Changes the static browser UI and sender fan-out. Element editing, readiness indicators, counters, retry controls, and hosting are out of scope.
